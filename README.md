# Jay Basu Product Design Portfolio

An interactive product portfolio focused on applied AI, accessibility, and the decisions that connect user needs with technical systems.

## Live portfolio

[jay-basu-product-design.vercel.app](https://jay-basu-product-design.vercel.app)

## Featured work

### Signal Studio

An evidence first AI workspace that helps creators turn community feedback into focused growth experiments. The prototype explores transparent model reasoning, signal correction, confidence, and measurable experiments.

### AccessFit

An accessible care companion concept for people adapting to prosthetic devices. The prototype focuses on low effort check ins, user controlled summaries, careful AI boundaries, and clearer clinician conversations.

## What is included

* Responsive portfolio and case study pages
* Interactive prototypes built with HTML, CSS, and JavaScript
* Product framing, decision journeys, design principles, and validation plans
* Complete implementation briefs for extending both concepts
* Keyboard navigation, semantic structure, reduced motion support, and accessible interaction patterns

## Run locally

No build step is required. Open `dist/index.html` in a browser, or serve the `dist` directory with any static file server.

## Project notes

Both projects are independent concept studies. All product data is illustrative, and the research sections clearly separate assumptions and proposed validation from completed research.
